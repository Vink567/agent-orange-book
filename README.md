# Agent 橙皮书

> 一份给普通人的 AI Agent 入门手册。

从会聊天，到会指挥。  
从问 AI 一个问题，到让 Agent 完成一件事。

这不是一本技术黑话手册，而是一份普通人也能看懂、能照着用、能马上上手的 Agent 指南。

## 这是什么

《Agent 橙皮书》是一份围绕 AI Agent 基础认知、真实工作流和普通人上手方法整理的中文指南。

它不是任何产品的官方文档，也不代表官方能力承诺；文中涉及的 Agent、Codex、ChatGPT、Claude Code、Cursor、GitHub 等产品功能，均以官方文档和实际版本为准。

## 内容包括

- Agent 的基础认知：它和普通聊天式 AI 有什么区别。
- Agent 的能力边界：它能做什么，不能替人确认什么。
- 面向普通人的使用方法：如何描述目标、拆解任务、检查结果。
- 资料整理 Agent 实战：把文章、PDF、链接、会议记录和调研材料整理成可复用资料。
- Twitter / X 资料采集实战：让 Agent 筛选近期高质量文章，并保存到 Obsidian 资料库。
- AI 热点报告实战：基于已整理资料，提炼核心观点、可引用表达、下一步行动建议。
- 自动复盘 Agent 实战：定期整理工作、学习、创作、编程和项目推进记录。
- PPT / 图文发布实战：把文章拆成 PPT、长图、封面和发布文案。
- 风险提醒：账号、文件、数据库、部署和重要操作都需要人工确认。
